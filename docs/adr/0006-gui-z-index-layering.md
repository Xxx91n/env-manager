# GUI z-index layering: titlebar z-50, modal/toast z-100

The custom Tauri titlebar uses `position: fixed` (v0.9.24 hard boundary), which places it above normal content flow. We set titlebar to `z-index: 50` (navbar level per TailwindCSS z-index convention) and all overlay surfaces (ConfirmDialog, InputDialog, Toast) to `z-[100]`. The titlebar must stay above scrolling content but must never suppress modal/toast overlays; z-50 < z-[100] guarantees both. Rejected: keeping titlebar at z-100 and raising overlays to z-110 (exceeds Tailwind z-50 semantic scale, future z-index work would need to track an ad-hoc ceiling). Rejected: aligning to Tailwind official z-20/z-30/z-50 scale (would require changing every existing z-[60] across the codebase, high regression risk for no semantic gain).
