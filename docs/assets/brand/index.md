# Env Manager — Brand Asset Guide

> "Adapts seamlessly to every environment."
> A self-adapting chameleon that orchestrates environment variables across Dev / Staging / Prod.

The chameleon logo is a 1:1 metaphor of the system architecture, not decoration.

## Visual Anatomy

| Geometry | Feature | System mapping | Mental model |
|---|---|---|---|
| Forward head with 45° beak | Sharp forward cut | CLI runtime instant injection (`run` / `exec`) | Precise targeting — no-latency injection into the target process |
| Concentric turret eye | Double ring, color-shifts with env | Single Source of Truth | State awareness — see which config context is active at a glance |
| Triple crest (three equal peaks) | 3 geometric serrations | Dev / Staging / Prod isolation layers | Tiered isolation — prevents configuration pollution |
| Inward spiral tail | 270° closed-loop arc | `.env` file lifecycle + sandbox sealing | Safe encapsulation — variables managed in a closed loop, no leaks |
